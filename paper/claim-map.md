# Claim-to-evidence map

Use this map with the [current paper](latex/main.pdf), [displayed-result map](result-map.json) and [reproduction guide](../docs/reproduction.md). Labels refer to the current LaTeX source. The default entry is `python tools/core.py reproduce --output build/replayed`.

The manuscript connects **recovery evidence → assigned values → repair credit**. Recovery of a familiar value is useful only when it serves the task's intended target; reference matching then determines whether the edit earns credit. Condition comparisons, knowledge-conflict tests and reference checks examine those questions with their respective inputs. The [revision binding](revision-binding.json) identifies the current 2026-10-26 manuscript and formal report; [revision provenance](revisions/README.md) distinguishes historical snapshots.

## Why these datasets

| Dataset | Diagnostic contribution | Manuscript location |
| --- | --- | --- |
| Hospital | Damaged names connect word forms, retained candidates and entity knowledge; restricted syllable names also expose a construction regularity | `sec:benchmarks`, `sec:recoverability`, `sec:build-hospital`, `sec:knowledge`, `sec:commercial` |
| Movies | Source-specific mappings contrast with errors that retain candidate values; assigned-director conflicts test preservation separately from factual recovery | `sec:build-movies`, `sec:knowledge`, `sec:conflict` |
| Beers | Formatting errors retain repair information, giving a model-dependent familiarity contrast and location-conflict control | `sec:build-beers`, `tab:beers`, `sec:conflict` |
| Rayyan | Spreadsheet transformations expose the reference's role in repair credit, through field checks and the actual scored input | `sec:quality`, `sec:rayyan-audit`, `sec:rayyan-rewards` |

Recovery cases are assigned to the evidence available for a cell, not to an entire dataset. Beers' reversible formats do not imply that every model is independent of familiar names. Rayyan is not a fourth four-condition experiment; Flights and Tax serve only the continuation probe. [Scope](../docs/limitations.md) describes the supported range.
