# CoRe 实验范围与核心主张冻结（v1.0）

> **冻结日期**：2026-10-09  
> **适用稿件**：*Cleaning or Recalling? Disentangling Memorization and World Knowledge in LLM-based Data Cleaning*  
> **证据锚点**：`CoRe-artifact` 提交 `5dfcde7`；冻结表清单 `data/manifests/MANIFEST_1002.json`；内部复现包 SHA-256 `8ff4d85c6f83b88234f55e7a66fef878b0356b332a5147355fbfc54a88f26516`  
> **冻结含义**：从本版开始，主线转入写作、核验和投稿准备；默认不再增加模型、数据集、基线、构造种子或新实验分支。

## 1. 论文故事的唯一主线

CoRe 不是提出一个更高分的清洗器，而是提出一套受控评测协议，用原版、新鲜实体、英文词替身和音节替身四个条件，区分基于大模型的数据清洗分数中的表内清洗能力、实体知识、拼写知识与可疑的记忆效应，并展示两个实际后果：真实实体可使经典基准高估模型在陌生数据上的修复能力；当表内记录与模型知识冲突时，模型可能改写本来正确的数据。

## 2. 冻结的实验范围

### 2.1 研究问题

| 编号 | 研究问题 | 回答它的实验 |
|---|---|---|
| RQ1 | 经典数据清洗基准上的 LLM 修复分数有多少来自记忆、实体知识和拼写知识？ | P1 逐行续写探针；P2 四条件分解；3 个构造种子；Qwen2.5 规模梯度 |
| RQ2 | 当表内证据与模型已知事实冲突时，模型会否覆盖正确数据？ | 近似实体条件；标准提示与“仅依据表内证据”提示 |
| RQ3 | 基准真值的质量是否会误导方法评价？ | Rayyan 机械转换检查、PubMed 分层核实和 TabClean 统一口径分析 |

### 2.2 数据集与用途

| 数据集 | 冻结用途 | 条件 |
|---|---|---|
| Hospital | 主要知识分解、规模梯度、对齐设置和近似实体 | 原版 O、新鲜 F、英文词替身 W、音节替身 S；F/W/S 各3个构造种子 |
| Movies | 实体知识、知识替代推理、对齐设置和导演冲突 | O/F/W/S；F/W/S 各3个构造种子 |
| Beers | 格式错误对照与城市知识个案 | O/F/W/S；不扩展构造种子 |
| Rayyan | 基准真值质量审计 | 不做四条件，不把修正版真值纳入本稿实验 |
| Flights、Tax | P1 记忆探针的补充数据 | 不纳入 P2 和主结论 |

### 2.3 模型、基线与设置

- **P2 主比较集（8个模型）**：DeepSeek-V4-Pro、Qwen3.8-Max、GLM-5.3、GPT-6.1-Sol、Qwen2.5-7B、Llama-3.1-8B、Qwen2.5-14B、Qwen2.5-32B-AWQ。
- **P1 辅助模型**：上述已归档模型中完成 P1 的子集，加 OLMo-2-7B-Instruct 和 OLMo-2-7B base；只用于“未发现记忆正证据”。
- **方法基线**：Baran 整表完美检测设置、Baran 对齐设置（3个固定种子取平均）、TabClean（DeepSeek-V4-Pro 底座，排除开发行）。
- **指标**：修复 F1，Hospital/Movies 主要报告身份列；接近零分时补报修对数；近似实体报告改写到真实属性的比例。
- **统计口径**：数据块上 2,000 次自助法；接近零分时使用配对块符号检验；同表差值或同类检验使用 Holm 校正；构造不确定性报告 3 个种子的范围。

## 3. 冻结的核心主张

### C1：真实实体知识会显著抬高 LLM 在实体密集清洗基准上的修复分数，而现有证据不支持把该差距解释为基准行记忆。

- Hospital 身份列上，8 个主比较模型的原版减音节替身效应为 `+0.19–+0.72`（跨3个构造种子）；这一差距可解释为显著的知识贡献，但不宣称所有模型都“大部分”依赖知识。
- Movies 身份列上，四个商用模型的新鲜减英文词替身效应为 `+0.14–+0.44`；开源模型的绝对修复分数太低，不用来支撑 Movies 的泛化主张。
- DeepSeek 在获得 20 个标注样例和错误位置后，Hospital 和 Movies 的新鲜减英文词替身差距仍为 `+0.22` 和 `+0.58`；该结果只作为 DeepSeek 的压力测试，不外推到所有模型。
- P1 中最高 hard-cell 准确率为 `0.085`，含错 hard cell 中的干净值泄漏数也极低。准确写法是“在所测模型和样本上，P1 未发现基准行记忆的正证据”，不得写成“证明没有训练污染”。

### C2：模型知识不仅提高分数，也可能在知识冲突时覆盖正确的表内数据。

- 在模型已知的 Movies 实体上，四个商用模型将表中“正确但不符合真实世界”的导演改回真实导演的比例为 `0.68–1.00`；Qwen2.5-7B/14B/32B 为 `0.14/0.69/0.70`。
- “仅依据表内证据”的提示将四个商用模型的 Movies 改写率降至 `0.00–0.40`，但对 Qwen2.5-14B/32B 作用很弱；因此只主张“约束提示可缓解但不可靠消除冲突”。
- Hospital 和 Beers 的所在地改写率为 `0–0.14`，效应明显依赖属性的唯一性；不宣称模型会普遍覆盖所有冲突属性。

### C3：基准真值本身的系统性损坏会奖励方法复现损坏，而非恢复外部世界中的正确值。

- Rayyan 的错误格中，722/722 个日期和 31/32 个页码真值可由脏值机械转换得到。
- 在标题可与 PubMed 匹配的分层核实中，按 948 个错误格的类型分布加权，真值错误比例估计为 `95.2%`（95% 区间 `91.2%–97.8%`）。该数字必须与“标题匹配、分层抽样与加权估计”的口径同时出现。
- 统一排除 150 个开发行后，TabClean 在 Rayyan 上的 F1 为 `0.71`；461 个修对中有 434 个（`94%`）是将正确日期改成基准的损坏格式。写作时只说“评价奖励了复现损坏”，不推断 TabClean 的设计意图。

## 4. 保留的辅助结论

1. **构造稳定性**：Hospital 总知识效应在3个构造种子之间最多相差 0.06，Movies 商用模型的实体效应总体稳定；不对单个小差值过度解读。
2. **有限的规模趋势**：Qwen2.5-7B/14B/32B 在 Hospital 上的总知识效应按每个构造种子保持大小顺序；不主张“知识依赖对所有模型、数据集和效应分量都随规模单调增长”。
3. **无知识方法的对照**：Baran 整表设置和 TabClean 在四条件上总体稳定，支持替身表并非必然更难；不再主张 LLM 在陌生实体上输给 Baran。
4. **Beers 是边界条件，不是普遍阴性对照**：格式错误对知识的依赖因模型而异；Qwen3.8-Max 的总知识效应为 `+0.24`，其他多数模型不支持该效应。
5. **GPT 音节解码是构造局限**：GPT-6.1-Sol 可从 24 个音节的小词表中推回 95 个唯一可还原伪词中的 74 个，使其 Hospital 音节替身分数偏高；因此其总知识效应是偏保守的估计。

## 5. 明确禁止的主张

- 禁止写“大模型没有记忆或训练污染”；只能写 P1 在所测范围内未发现正证据。
- 禁止把 `O−F` 解释为纯记忆效应；它混合了表难度和真值性质差异，只是辅证。
- 禁止写“所有 LLM 的大部分分数都来自知识”；必须限定数据集、列组和模型。
- 禁止写“知识依赖普遍随参数规模增长”；只有 Qwen2.5 在 Hospital 上的总知识效应支持这一趋势。
- 禁止写“格式错误不依赖知识”；Beers 的 Qwen3.8-Max 是反例。
- 禁止恢复“LLM 在陌生实体上输给传统方法”或“排名反转”主张；对等设置不支持它。
- 禁止把 Movies 上的商用模型结论外推到开源模型；后者分数接近零。
- 禁止写“模型遇到知识冲突就会改写数据”；效应集中在导演这类唯一性强的属性。
- 禁止写“Rayyan 95% 的文献记录是错的”；`95.2%` 指加权估计的错误格真值问题，不是整行或全部文献的错误率。
- 禁止推断 TabClean “故意”利用基准损坏；只描述它的输出和评价结果。

## 8. 变更控制

冻结后只有三类情况可以重开实验：

1. 发现会使 C1–C3 中任一主张失效的数据或代码错误；
2. 投稿规则或审稿意见明确要求的补充实验；
3. 公开复现包为解决许可问题而必须重建数据，且重建结果与冻结表不一致。

触发变更时，必须同时：将本文档升版；记录原因、受影响主张和旧/新结果；重生成所有受影响图表、输出清单和复现包校验和；再次执行干净解压验证。

## 9. 冻结后的唯一开发队列

1. 对照本文档收紧摘要、引言、Finding 框和结论的主张边界。
2. 在 Overleaf 上编译并将正文控制在 PVLDB EA&B 页数内。
3. 完成两轮内部审读，每条意见优先通过收紧表述、补充局限或增强证据导航解决，不默认转化为新实验。
4. 完成复现包的作者信息与 Movies/IMDb 许可处理，再生成可公开版。
5. 确认作者、单位、合格审稿人和投稿链接。

**冻结结论**：现有证据已足以支撑一篇以“受控评测方法＋知识高估＋知识冲突＋真值质量”为主线的 EA&B 论文。后续质量增益的主要瓶颈是主张精度、论文结构、图表可读性和复现包合规，而不是实验数量。
