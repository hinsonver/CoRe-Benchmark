## Acceptance checks

The 506 checks cover 21 tables. The [complete table source](../latex/tables/checks.tex) preserves the original categories and operations.

| Category | Checks | What is checked |
| --- | ---: | --- |
| Structure | 67 | Shape and columns; error cells where the original has them; identical non-identity cells; different seeds with shared fresh clean tables. |
| Error kinds and counts | 137 | Per-column kinds and counts as in the original; formatting rules; errors only in rows that carry them. |
| Error strength | 15 | Characters replaced per error cell within the tolerance of the original. |
| Naming and leakage | 263 | One fictitious value per real value and back; no real value reused; no word of a real title; title shapes no closer to real ones than chance; names that look like names. |
| Fresh entities | 6 | No benchmark entity where new entities are required; locations checked against sources. |
| Reproducibility | 18 | Every table rebuilt byte for byte under two hash seeds. |

The checks follow each family's fresh-source design: Hospital F uses newer rows largely about the same institutions. The tables pass 505/506 checks. Hospital W at seed 0 has a maximum error-strength difference of 10.5 percentage points, exceeding the eight-point tolerance by 2.5 points. Seeds 1 and 2 pass, with all error positions unchanged. [Construction and acceptance](01-构造与验收细则.md) gives the thresholds; [Archived sensitivity checks](07-归档敏感性与输出核验.md) give the passing-seed contrasts without replacing the frozen main table.

## TabClean: archived output evidence

The effective E4 archive is `artifacts/raw_outputs/e4/`, corresponding byte for byte to the effective inputs and outputs in `实验A-记忆性/results/e4/`. Historical `_failed_1001`, `_fresh_v2`, `_movies_v2_1002` and `_beers_v3_1002` directories are not substituted for these final files. Execution logs are under `实验A-记忆性/results/logs/e4_tabclean_<condition>.log`.

All twelve reported condition outputs have successful full-table execution logs. The 150 development rows match `sample(n=150, random_state=42)` and are excluded from the scores. On Movies, the original, fresh, word and syllable conditions repair 0, 0, 5 and 0 identity cells, respectively, out of 319, 313, 319 and 319 errors after exclusion. These counts explain the displayed near-zero F1 values without treating the runs as aborted executions.

For a Beers example outside the development rows, `San Francisco CA` in City and an empty State become `San Francisco` and `CA`, matching the reference. Both pieces of information are present in the dirty input. All 104 non-development city-error rows in Beers O have the correct city and state in the final output. The generated program bodies were not retained in this effective archive, so the example describes observed edits, not a recovered internal rule. The [reproduction guide](../../docs/reproduction.md#what-each-scoring-route-checks) distinguishes the supported scoring and replay entries; input and output versions remain hash-bound by the package manifests.
