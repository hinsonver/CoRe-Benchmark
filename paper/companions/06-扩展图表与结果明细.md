## Acceptance checks

The 506 checks cover 21 tables. The [complete table source](../latex/tables/checks.tex) preserves the original categories and operations.

| Category | Checks | What is checked |
| --- | ---: | --- |
| Structure | 67 | Shape and columns; error cells where the original has them; identical non-identity cells; different seeds with shared fresh clean tables. |
| Error kinds and counts | 137 | Per-column kinds and counts as in the original; formatting rules; errors only in rows that carry them. |
| Error strength | 15 | Characters replaced per error cell within the tolerance of the original. |
| Naming and leakage | 263 | One fictitious value per real value and back; no real value reused; no word of a real title; title shapes no closer to real ones than chance; names that look like names. |
| Fresh entities | 6 | No benchmark entity where new entities are required; locations checked against sources. |
| Reproducibility | 18 | Every table rebuilt byte for byte under two hash seeds. |

The checks follow each family's fresh-source design: Hospital F uses newer rows largely about the same institutions. The tables pass 505/506 checks. Hospital W at seed 0 has a maximum error-strength gap of 10.5 percentage points against an eight-point tolerance, with error positions unchanged. [Construction and acceptance](01-构造与验收细则.md) gives the thresholds and complete distribution.

## Full model comparison and presentation generation

The [full eight-model scale plot](../latex/figures/fig6_scale.pdf) is used in the main paper, with the [frozen scale CSV](../../results/figures/fig6_scale.csv) available for inspection.

The integrated presentation projection reads the complete frozen table sources, checks their non-caption content, restores the current manuscript captions, and adds `whole_table.tex` and `rayyan_checks.tex`. From the repository root with the replay environment activated, write to a new directory:

```sh
PYTHONPATH=code python -m src.paper_presentation \
  --source-tables results/tables --output build/display-only
```

This repository includes the current presentation projection. The [SHA-256 manifest](../../MANIFEST.sha256) binds the packaged sources and products; the [result map](../result-map.json) identifies the current main-paper displays.
