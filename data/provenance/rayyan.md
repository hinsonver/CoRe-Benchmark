# Rayyan provenance

The Rayyan table is inherited from the Raha/Baran benchmark. CoRe uses it for a
ground-truth quality audit and method analysis, not for the four-condition
construction. The archived audit stratifies mechanically transformed date and
page cells and records external PubMed checks used in the paper analysis.

The audit should not be regenerated silently because external metadata can
change. Before publication, consider notifying the upstream benchmark authors
and review redistribution terms for the inherited table.
