# Hospital provenance

The original Hospital table is inherited from the Raha/Baran benchmark. The
fresh table combines CMS Timely and Effective Care and Hospital General
Information releases dated 2026-07-22. It contains 1,000 rows from 34 hospitals;
33 hospitals are shared with the original table. Constructed surrogate tables
replace identifying fields while preserving the experimental error design.

Embedded `provenance.json` files record construction statistics. The original,
fresh, and surrogate table redistribution terms must be reviewed before public
release.
