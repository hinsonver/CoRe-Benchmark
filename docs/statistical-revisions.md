# Current statistical presentation

The current paper and 22-page supplementary technical report use two corrections to the statistical presentation. Input tables, saved replies and original summaries remain unchanged. No new model responses were generated.

## Continuation counts

Current replay uniformly applies the existing full-source structural screen to all 168 continuation archives (9,600 trials). It reads separately bound [integer counts](../results/derived/uniform_continuation.json), verifies their [source binding](../data/manifests/UNIFORM_CONTINUATION.json), and selects maxima and pools leakage with [the current loader](../code/src/uniform_continuation.py). The [scoring guide](continuation-scoring.md) describes the raw and aggregate entries. Report §2.5 defines the screen, parsing denominators and row-held-out sensitivity.

The largest hard-cell accuracy remains 32/375, displayed as .085. The screen uses full-table modes, successors, approximate functional dependencies and previous-value ±1. Frequency queries subtract the target vote; dependency eligibility remains fixed. Leakage uses the full clean table and clean predecessor as an additional oracle-assisted screen. Absence means absence from the corresponding context column, and cell rates condition on parsed rows. These rules define a diagnostic exclusion, not an input-matched prediction competitor or an estimate of memory prevalence.

Twelve early saved summaries differ from this uniform convention. They are retained as historical results; compatible counting behavior does not establish recovery of their original source revision. Adding `--presentation frozen` reproduces the original archived scores and formatting rather than the corrected current display.

## Beers city comparisons

DeepSeek has 10 versus 3 chunks, giving adjusted p=1323/2048, displayed as .646. Qwen3.8 has 4 versus 15, giving 1259/8192, displayed as .154. The former display applied Holm to already rounded probabilities and showed .644 and .152. Both comparisons remain non-significant; the other six adjusted values and the separate O-S bootstrap results are unchanged.

The two numerical table revisions are generated by the current source. The explanatory verification table also identifies the uniform continuation counts. The other 16 current table sources, all eleven figure CSVs and all fifteen original frozen table sources are byte-preserved. Other cleaning contrasts, conflict rates, reference-check estimates, intervals and significance decisions are unchanged. Historical original source bindings, raw archives and fixed release assets retain their previous identities.
